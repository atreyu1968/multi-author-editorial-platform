### 15. admin.books
**Descripción:** Gestión de libros (muy extenso - incluye todos los campos de configuración de libros)

Debido a la extensión de este namespace (más de 200 keys), se recomienda consultar directamente la base de datos para obtener la lista completa. Los principales grupos son:

- **Información básica:** título, descripción, ISBN, género, etc.
- **Configuración de venta:** precios, formatos, stock, archivo digital
- **Landing page:** hero, sinopsis, características, galería, premios
- **Material promocional:** mapa conceptual, árbol genealógico, notas de prensa, medios adicionales
- **SEO:** título, descripción, keywords
- **Personalización:** background image/color
- **Tiendas externas:** enlaces a Amazon, etc.

---

### 16. admin.series
**Descripción:** Gestión de series de libros

Similar a `admin.books`, este namespace es extenso con más de 100 keys. Grupos principales:

- **Información básica:** nombre, descripción, orden de libros
- **Configuración visual:** imagen de portada, background
- **SEO:** optimización para buscadores
- **Gestión de libros:** agregar/ordenar libros de la serie

## 📝 Notas para Traductores

### Formatos de Variables
Algunos textos contienen variables que deben mantenerse sin traducir:
- `{provider}` - Nombre del proveedor
- `{count}` - Números/contadores
- `{name}` - Nombres dinámicos

### Caracteres Especiales
- Mantén los caracteres HTML como `&nbsp;`, `&quot;`, etc.
- Respeta las comillas dobles `"` cuando sean parte del texto

### Consistencia
- Usa los mismos términos para conceptos similares en toda la traducción
- Mantén el tono profesional pero accesible
